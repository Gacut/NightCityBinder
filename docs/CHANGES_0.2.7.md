# 0.2.7 — zwijane wyszukiwanie bindera

Usunięto powielony opis nieoficjalnej aplikacji nad polityką prywatności.
Nazwa i statystyki bindera mają wspólny, ciaśniejszy nagłówek.
Cyjanowa lupa po prawej od statystyk rozwija pole nazwy/numeru pod nimi.
Pole domyślnie ukryte. Ponowne kliknięcie chowa pole, zamyka klawiaturę
oraz czyści filtr, żeby ukryta fraza nie ukrywała kart.

Sprawdzono podgląd 360x800, otwieranie/zamykanie pola i wyczyszczenie filtra,
usunięcie opisu ustawień. 54 testy i Ruff poprawne.
Nowego APK nie zbudowano. scripts/build_android.sh tworzy
NightCityBinder-0.2.7-debug.apk.
